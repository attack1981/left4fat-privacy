Политика конфиденциальности Left4Fat

Последнее обновление: сентябрь 2026

This document is in Russian, the app's primary language. In short: only with your consent, Left4Fat sends food photos and descriptions (and, for tips, your logged meals and basic profile data) to third-party AI — Anthropic Claude and DeepSeek. It reads Apple Health data and writes only water intake; Apple Health data is never stored in iCloud or shared with family members. Your data syncs via your own iCloud account. No account/password, no ads, no analytics/tracking SDKs. Contact: storozhevskaya.8@gmail.com.

Left4Fat («Приложение») — приложение для подсчёта калорий с распознаванием еды по фото. Ниже — честное и полное описание того, какие данные обрабатываются и как.

Учётные записи

Приложение не требует регистрации, логина или пароля. Профиль (рост, вес, цель и т.п.) хранится локально на устройстве. Для синхронизации между вашими устройствами используется ваш собственный Apple ID (iCloud) — мы не имеем доступа к этим данным как компания. Вес, полученный из Apple Здоровья, в iCloud не синхронизируется.

Какие данные обрабатываются

Анализ с помощью ИИ — только с вашего согласия

Перед первой отправкой данных сервисам искусственного интеллекта приложение объясняет, что и кому передаётся, и спрашивает разрешение. Согласие можно отозвать в любой момент: Настройки → Разрешения → «Анализ еды с помощью ИИ». Без согласия данные ИИ не отправляются, а еду можно добавлять из базы продуктов.

С вашего согласия передаются:

  • фото еды и этикеток (сжатые, без геолокации и EXIF) — сервису Claude (Anthropic) через прокси-сервер посредника, для распознавания продуктов и расчёта калорий/БЖУ;
  • текстовые и голосовые описания еды (голос распознаётся средствами Apple, ИИ получает только текст) — сервису Claude (Anthropic);
  • описание своего продукта («Добавить свой продукт по описанию») — сервису DeepSeek, а если он недоступен — Claude (Anthropic);
  • для разборов приёмов пищи и советов ИИ-тренера — записанная еда, ваши нормы и данные профиля: пол, возраст, цель, процент жира тела, обхват талии, сожжённые калории — сервису Claude (Anthropic).

Имя, email, контакты и Apple ID сервисам ИИ не передаются.

Поиск продуктов

Если продукта нет в базе приложения, название продукта (текст запроса, без личных данных) может отправляться в открытую базу Open Food Facts, откуда приложение берёт данные о пищевой ценности (лицензия ODbL).

Данные Apple Health (по вашему разрешению)

При включении интеграции со Здоровьем приложение:

  • читает: сожжённые калории, шаги, вес, процент жира тела (если есть умные весы), объём выпитой воды;
  • записывает: только объём воды, которую вы добавляете через приложение (в том числе напитки из дневника).

Данные из Здоровья не сохраняются в iCloud, не попадают в резервную копию и не передаются участникам «Семьи». Сервисам ИИ часть из них (процент жира тела и сожжённые калории) передаётся только для советов и только с вашего согласия — см. выше.

История питания и профиль

Записи о приёмах пищи (продукты, БЖУ, дата, фото еды) и настройки профиля хранятся локально на устройстве и синхронизируются в ваше приватное облако iCloud (CloudKit) — доступ к нему есть только у вас через ваш Apple ID. Туда же сохраняется резервная копия (кроме данных из Apple Здоровья).

Функция «Семья»

Если вы присоединяетесь к семейной группе, её участникам становятся видны: ваше отображаемое имя и фото профиля, записи о приёмах пищи (список блюд, калории, БЖУ, дата, уменьшенная копия фото еды), добавленные вами продукты, ваши дневные нормы калорий и БЖУ, прогресс в общих челленджах. Вес, процент жира тела и другие данные из Apple Здоровья участникам не передаются. Эти данные хранятся в общей базе CloudKit приложения, и приложение показывает их только участникам вашей группы.

Push-уведомления

Напоминания (о воде, челленджах, дневной норме) формируются локально на устройстве. Тексты разборов после приёма пищи и советов ИИ-тренера составляет сервис Claude (Anthropic) по данным, перечисленным в разделе об ИИ, — только с вашего согласия. Уведомления о новых записях в семейной группе приходят от участников вашей группы.

Чего мы НЕ делаем

  • Не используем рекламные сети и SDK для трекинга.
  • Не используем аналитические сервисы (Firebase, Mixpanel и т.п.).
  • Не продаём и не передаём ваши данные третьим лицам в маркетинговых целях.
  • Не требуем email, телефон или другие персональные данные для использования приложения.

Хранение и удаление данных

Вы можете в любой момент удалить отдельные записи истории питания прямо в приложении. Полное удаление всех данных приложения (включая копию в iCloud) происходит при удалении приложения с устройства и удалении его данных из iCloud (Настройки iPhone → [ваше имя] → iCloud → Управление хранилищем).
